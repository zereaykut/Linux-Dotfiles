# Open-Meteo-API
Retrieve and save data from Open Meteo API
For more infrmation: https://open-meteo.com/en/docs

## How to Use
Clone the repo
```shell
git clone https://github.com/zereaykut/Open-Meteo-API.git
cd Open-Meteo-API
```

Create python environment
```shell
python -m venv venv
```

Activate environment in Mac/Linux 
```shell
source venv/bin/activate
```

Activate environment in Windows 
```shell
.\venv\Scripts\activate
```

Install required packages
```shell
pip install -r requirements.txt
```
